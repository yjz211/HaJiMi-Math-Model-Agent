# HaJiMi Math Model Agent

HaJiMi 数学建模桌面助手，支持从题目与材料整理、建模求解、结果验证到绘图、论文撰写及提交包生成的工作流。

## 下载与安装

在 [Releases](https://github.com/yjz211/HaJiMi-Math-Model-Agent/releases/latest) 下载 Windows x64 安装包，运行后按向导选择安装目录。

安装包包含 Python、LaTeX、Shell 和字体等离线工具运行时，不含已有建模项目或测试会话。使用 AI 模型仍需配置模型供应商和相应账号/API 凭据，并需要网络连接。

本地构建未做代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。下载后可以使用 Release 附带的 SHA256SUMS.txt 核对文件完整性。

## 当前版本

- 第七阶段至第八阶段交接时选择鲜艳舒适型或稳重科研型绘图。
- 支持并鼓励有真实数据与几何依据的三维空间图及工程图。
- 整题 DATA 图最低 8 张，建议 18–30 张。
- 应用、托盘和安装器采用统一的 HaJiMi H 图标。
- Windows x64 安装包只保留对应平台的 esbuild 二进制；保留 esbuild 功能和其他运行依赖。

本仓库用于分发安装包与版本说明，当前未上传开发源码。
