# HaJiMi v0.1.2

- 严格模式采用 0.1.0 工作流；清爽模式保留 0.1.1 流程，第八阶段与严格模式一致。
- 第八阶段保留图表、写作、审查三个小阶段，允许回退补齐缺失凭证，避免门禁锁死。
- 绘图规划移至第八阶段，在选择绘图模式后开始；修复旧工作区绘图资源路径残留。
- Windows 离线运行时内置 adjustText 1.4.0，额外 Python 包默认安装到独立缓存目录，防止修改签名运行时。
- 移除 SciencePlots 的自动安装、样式调用及相关说明，保留既有配色。

## 安装

本次发布 Windows x64 完整安装包，包含受管运行时和 draw.io。安装包未使用 Windows 商业代码签名证书，系统可能显示 SmartScreen 提示。运行时继续使用 local-test 签名方案进行完整性校验。macOS/Linux 安装包不在本次发布范围。

- 发布框架安全补丁：Next.js / eslint-config-next 升至 16.3.4，更新锁定依赖；发布前 npm audit 为 0 项已知漏洞。
