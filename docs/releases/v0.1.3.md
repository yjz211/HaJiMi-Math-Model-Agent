# HaJiMi v0.1.3

本版本继续提供 Windows x64 安装包与自动更新清单。

## 更新内容

- 为 108 份内置绘图配方建立稳定 ID，并保留旧编号与 `custom` 接口兼容。
- 同步主流程与原始兼容流程的绘图配方路由，避免第 8 阶段引用错位。
- 保存图像时保留作者布局，不再自动移动文字、放大子图或强制紧凑裁剪。
- 保留原有绘图风格、配色、导出格式、清晰度检查与完整配方正文。
- 全自动运行期间始终保留聊天输入框，允许随时停止、纠偏、补充指令或切换模式；自动续跑和阶段门禁保持不变。

## Windows 安装说明

Windows 安装包目前未进行代码签名。首次下载或启动时，Microsoft Defender SmartScreen 可能显示提示；请核对下载来源为本项目的 GitHub Release 后再继续安装。
