# HaJiMi Math Model Agent v0.1.1

本次更新重点调整了 0—9 阶段工作流的运行方式：减少无意义的流程消耗，同时保留建模、验证、图表和论文交付所需的完成检查。

## 主要更新

- 新增两组相互独立的模式选择：全自动 / 半自动，以及清爽快速运行型 / 严格清单门禁型。模式只在第 0 阶段材料确认后询问一次，不再重复询问或组合成四个选项。
- 清爽模式减少重复登记、证据冻结、门禁和审计调用，把更多上下文与 Token 留给模型求解；严格模式保留逐项清单、证据快照和交付审计。两种模式都保留多方法比较、独立验证、必要实验、图表和完整论文检查。
- 修复全自动模式遇到阻塞后反复自我唤醒的死循环。当前阶段标记为阻塞或连续两次没有实质进展时，程序会暂停自动续跑、保留现有成果并展示具体阻碍；用户也可以随时停止、补充指令或切换模式。
- 修复第 8 阶段验证需要补证据、但相关工具仅在更早阶段可用的矛盾。第 8 阶段现在可以补实验、登记证据并重新冻结，然后继续验证。
- 严格模式恢复第 8 阶段 `figures → writing → review → ready` 的顺序、文件哈希固定和定向返工规则；清爽模式允许更灵活地修正，但不能绕过实际完成检查。
- 增加统一的阶段完成检查和论文质量检查，防止缺图、缺结果、缺公式基线、PDF 不完整或关键小问未完成时被误标为完成。
- 改进文件定位：新项目默认建立在桌面的 `HaJiMi\projects` 中；第 0 阶段完成后会显示项目完整路径，并说明它与左侧项目一一对应。第 8 阶段交付时也会直接显示论文 PDF 的完整路径。
- 减少工具调用中的重复版本冲突、重复审计和不必要的人工门禁，使全自动与半自动流程更容易中止、修复和继续。

## 安装提示

- Windows 安装包尚未代码签名，安装时可能出现 SmartScreen 提示。
- macOS 安装包尚未签名和公证，首次打开时可能出现 Gatekeeper 提示。
- Linux `.deb` 尚未进行 debsig 签名；应用内更新安装时需要 root 授权，下载完整性由 `latest-linux.yml` 中的 SHA512 校验。
