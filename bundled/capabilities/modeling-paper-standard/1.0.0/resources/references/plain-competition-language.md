# 竞赛论文直白语言最高优先级契约

版本：1.0  
来源：用户 2026-08-09 明确指令；`practice_009` 从高压缩科研化版本到直白版本、再到防御性语言逐句修订的真实写作证据。

## 1. 最高原则

数学建模竞赛论文首先要让评委快速看懂“研究什么、怎样做、得到什么、方案怎样用”。在不改变事实、公式、数值和结论范围的前提下，读者可见语言必须通俗、直接、肯定，禁止模仿科研论文的高压缩表达。

本契约在**语言风格层**具有最高优先级。它不覆盖当届官方规则、用户确认的固定结构、数学定义或证据边界；它决定这些内容怎样写给评委看。

适用范围包括题目、摘要、标题、正文、答案框、图题、表题和表格文字。公式、标准数学符号、参考文献著录及独立代码文件不按日常词汇改写，但公式前后仍须使用直白中文解释。

## 2. 什么是高压缩语义

高压缩语义是把多个对象、动作、条件或判断塞进一个短术语，让读者必须自行还原其含义。常见形式包括：

1. 把内部工作步骤写成名词，如“冻结模型”“回填”“发布门槛”；
2. 用抽象空间词代替实际范围，如“支持域”“域内/域外”；
3. 用系统术语代替明确动作，如“拒识”“门控”“正式层/探索层”；
4. 自创多层复合词，如“代理发布门槛”“两保真序贯闭环”“寿命头/轨迹头”；
5. 在标题或一句话中连续堆放多个模型名、缩写和抽象名词。

判断方法：第一次接触本题的评委读完一句话后，如果还不能直接回答“谁对什么做了什么、在什么条件下、得到什么”，该句就存在语义压缩，必须展开。

## 3. 强制改写顺序

每个关键句优先按下列顺序写：

`题目对象 → 实际动作 → 直接结果 → 原因或用途 → 适用范围 → 必要术语`

标准模型名或专业术语只有在确实有助于复核时才保留。第一次出现时，先写它在本题中完成的具体动作，再在后句或括号中给出名称。例如：

- 先写“限制相邻变量相关造成的过大回归系数”，再写“采用 Ridge 回归”；
- 先写“从没有其他方案能同时在两个目标上更优的实测方案中选择”，再写“构造 Pareto 前沿”；
- 先写“按轮次提出方案、完成试验并更新模型”，再在确有必要时写“序贯试验设计”。

标准术语不等于必须使用。日常语言已经准确时，直接使用日常语言。

## 4. `practice_009` 形成的稳定替换

以下只吸收表达方式，不迁移该题模型、数据或结论：

| 高压缩或内部说法 | 竞赛论文写法 |
|---|---|
| 冻结模型 | 在查看测试结果前确定模型 |
| 支持域 | 有相近实测数据的范围 |
| 域内/域外 | 在训练数据覆盖范围内/超出训练数据范围 |
| 发布/拒识 | 给出预测/转入校准后再预测 |
| 门控 | 按明确条件判断是否进入下一步 |
| SOC 暴露 | SOC 区间内的电流作用量 |
| 正式层/探索层 | 实测方案选择/下一批试验建议 |
| 回填 | 用全寿命真实结果更新早期预测 |
| 代理发布门槛 | 预测模型优于简单基准后再提出新方案 |
| 寿命头/轨迹头 | 寿命预测模型/容量变化模型 |

表中词语进入读者可见正文时按右栏改写。内部代码、测试和审查记录可保留左栏术语。

## 5. 防御性写法改为肯定写法

竞赛论文用结果和动作说明边界，不在每个结论后反复写“不能、不得、不代表、不意味着、不应理解为、只能说明”。必要边界仍须保留，但优先改成可执行的肯定句：

| 防御性写法 | 肯定、直白的写法 |
|---|---|
| 模型不能直接用于新批次 | 新批次先用少量样本完成校准，再进行预测 |
| 该批次不提出候选 | 该批次保留实测方案，模型超过简单基准后再进入新方案搜索 |
| 早期预测不能替代全寿命结果 | 早期预测负责筛选，全寿命结果负责最终更新 |
| 不能在全部连续参数中外推 | 搜索范围限定在有相近实测数据的区域 |
| 结果不稳定，暂不下定论 | 两种处理下结果方向不同，当前影响方向尚未确定 |
| 不能证明因果关系 | 本文描述当前样本中的关联；因果判断需要随机对照试验 |
| 不能称为已验证最优方案 | 该方案进入下一批试验，完成验证后更新实测方案集合 |
| 这不意味着陌生策略更容易预测 | 两组误差差异主要来自目标值跨度不同 |

执行规则：

1. 先写已经观察到的事实、数值或比较；
2. 再写据此采取的动作或得到的结论；
3. 适用范围用一条肯定句就近说明，不在后续段落重复兜底；
4. 真实负结果直接写成“结果是多少、说明什么、下一步怎样处理”，不包装成连续否定句；
5. “肯定写法”绝不等于夸大。有限搜索、相关关系、预测范围和未验证建议仍按真实证据表述。

## 6. 句子与段落要求

- 一句话只承担一个主要判断；长句优先拆成“事实—原因—行动”。
- 主语和对象必须清楚，不连续使用四个以上抽象名词构成长定语。
- 少用名词化表达；能写“比较、计算、选择、校准、更新”，就不写“比较机制、计算范式、选择层、校准闭环、更新链路”。
- 标题直接写题目对象和任务，不用复合术语制造“高级感”。
- 每段至少能找到本题对象、实际动作和结果/用途；模型名不能替代这三项。
- 图题、表头和答案框同样执行本规则，不能把高压缩词藏在图表中。

## 7. 人工审查门

自动检查只能发现已知词语和防御性句式，最终必须逐段人工执行：

1. 圈出所有自创术语、抽象复合词和连续模型名；逐一改成对象与动作；
2. 圈出“不能、不得、不代表、不意味着、不应、只能、才允许”等句式；除数学约束和确有必要的一次边界外，全部改成事实或行动；
3. 遮住标题，确认每段仍能看出正在处理什么对象；
4. 让一句话只保留一个主要结论，拆开过长定语和多重转折；
5. 复核改写前后的公式、数字、单位、条件和结论范围完全一致。

出现下列任一情形即为阻断项：

- 读者可见正文含自创的高压缩术语；
- 标题、摘要或答案框以高专业性复合词代替题目动作；
- 专业术语首次出现时没有本题化直白解释；
- 同一段连续使用两处及以上防御性否定；
- 全文反复用否定句保护结论，而没有写出对应的正面事实和行动；
- 为追求直白而删除假设、单位、约束、适用范围或失败结果。

## 8. 验收证据

交付候选稿前必须：

1. 运行 `scripts/check_latex_language.py`；
2. 保存高压缩词与防御性句式的审查结果；
3. 对自动检查未覆盖的自创词进行人工清单式复核；
4. 抽取摘要、各问答案框、主要结果段和全部标题做一次限时阅读；
5. 确认任何评委都能直接找到“问题、动作、结果、用途和范围”。
