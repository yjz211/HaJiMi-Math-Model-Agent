# 论文与图表 QA 记录模板

> 仅在 `paper_training: enabled` 时使用。每张正式图和每个最终章节都需要能回到机器结果与证据清单。

## A. 论文模板与结构

- [ ] 已确认当届官方提交/页数/匿名/AI 披露要求；若有冲突，已覆盖通用模板规则。
- [ ] 若格式基准是旧 `.doc`，已记录 Word 原生渲染器与版本；未用 LibreOffice 分页替代最终 Word 版式证据。
- [ ] 标题、摘要、关键词、问题重述、问题分析、假设、符号、逐问模型/求解/结果、检验、评价、参考文献和附录结构完整或已说明不适用项。
- [ ] 每个小问都有明确回答；摘要在结果冻结后写作，且只含正文可追溯的方法与数字。
- [ ] 公式为原生可编辑公式，变量首次出现有解释；符号、单位、术语和图表编号一致。
- [ ] 每一条“最优/显著/准确/稳定/鲁棒”表述都有对应证据或已改为克制表述。

## B. 图表合同与数据完整性

| 图号 | 核心结论 | 单图/多子图与理由 | 数据/证据来源 | 图型与后端 | 统计/约束 | 主要审稿风险 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

- [ ] 每张图已独立选择 `single` 或 `multi-panel`；一个证据对象足够时采用单图，多子图只用于必须共同阅读的不同证据。
- [ ] 多子图的每个面板均回答独立问题并支持同一结论；最终论文尺寸下文字仍清晰。单图未添加无意义面板字母、空轴或图例专用面板。
- [ ] 每个面板有独立证据作用；不存在只为凑图的重复面板。
- [ ] 已使用 `modeling-plot-suite` 对账完整图表清单；完整论文至少有一张总览流程图，并保存语义合同、可编辑源、SVG/PDF 主文件和 QA 报告，或已记录用户明确批准的豁免。
- [ ] 数据图、真实构型、解析物理/工程图、地图/网络图和流程图均选择了正确工作流；生成式插画未替代定量或精确工程证据。
- [ ] 总览流程图覆盖问题分解、模型路线、求解、验证和逐问输出；所有节点可追溯，决策出口有标签，无悬空或不可达节点，也不包含内部 Agent 工作流。
- [ ] 数据筛选、聚合、转换、随机种子和前后计数已记录；没有模拟数据或便利筛选混入正式图。
- [ ] 跨图颜色、类别顺序、单位和名称一致；红绿不是唯一编码。
- [ ] 中文论文的图内标题、坐标轴、图例、色条、状态和说明已使用自然中文；仅数学符号、SI 单位、通用缩写和正式专名按规范保留，未遗留英文示例标签。
- [ ] 已验证中文字体无缺字、乱码或异常回退；最终字号通常集中在 8.5—10 pt，常规字号比例不超过 1.25，超过 1.35 的情况已返工或记录理由。
- [ ] 每张图有图题、必要的图例/直接标签、坐标与单位；正文实际引用该图。
- [ ] 作图源码预检已运行，所有失败关闭，警告及理由已记录。
- [ ] 复用的代码、模板、图片和第三方素材已分别核对许可、来源与署名；示例图未直接混入正式论文。
- [ ] 最终 Word/PDF 中逐图视觉检查通过：无裁切、重叠、模糊、过小文字或空白失衡。
- [ ] AI 已实际查看成图与论文整页，主动判断层级、对齐、留白、视觉重心、字体、颜色、线宽、拥挤度和跨图一致性；已自行完成常规美化返工，未把首个技术可用版本直接当成终稿。

## C. 终稿可追溯性与审稿结论

- [ ] 论文中的每个关键数值可回溯至 `results/evidence_manifest.md` 或机器可读结果。
- [ ] 结果、图表、公式、结论和附录代码版本一致。
- [ ] AI 没有引入未使用模型、虚构数字/图号/引用或未验证结论。
- [ ] 已记录未解决限制、依赖的假设和不能泛化的结论。
