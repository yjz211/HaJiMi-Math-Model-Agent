# 明亮新颖绘图模式 expressive

用户选择本模式时，优先于默认项目名风格抽签。沿用原版完整指南、配方预取、真实数据及最终尺寸预计算；本模式不改变计算结果。它是用户授权的设计偏好，不声称是 原始预设。

## 整套设计
- 白底、明亮青绿/珊瑚/蓝/暖杏配合，使用现有 coral 色板，按项目标记的自定义顺序读取，保留淡紫作为辅助；基础版式 clean_open。颜色通过 setup_style 后的 pu.PALETTE / pu.COLORS 读取。浅背景、清晰原色线条和白边标记形成层次，避免荧光色大面积铺满和整套单一深色。
- 每图在 PAPER_PLAN 中先写一句要回答的问题，并比较两种有真实数据依据的表达方式，选择信息互补、视觉鲜明的一种；只生成选中的方案。
- 新颖是明确设计目标，不能只换鲜艳颜色，也不能用增加子图数量代替新颖。主动检索适合数据的新颖单图、同坐标系融合图与多面板组合图，按表达收益选择，不默认多面板优先。
- 融合图：在一个坐标系内叠合多种互补图形编码，最终仍是一套坐标轴，而非并排子图、边缘小图或局部放大窗。例如真实散点＋等高线/区域填色、折线＋真实区间带＋关键样本、空间地形＋测线＋覆盖轮廓、同类别位置的小提琴＋箱线＋原始散点。积极评估这种融合机会；各层应表达同一对象或共享坐标含义，用透明度、线型、标记和绘制顺序建立主次。区间、密度、分布必须有真实数据依据，不随意拟合或虚构；不可把不同单位强塞同轴，双轴也不当成融合的默认捷径。
- 多面板组合图仍值得鼓励，例如空间图＋剖面、主图＋边缘分布或局部放大，但只在不同视角确有互补信息、单坐标系不易清楚表达时采用。无需每张都组合，也无需为保留清晰单图逐张辩护。新颖单图、融合图和组合图都可以形成视觉亮点，不设多面板或融合数量配额。
- 在规划理由中说明选中图型的信息收益：融合图写各图层的含义与共同坐标，组合图写各面板贡献；不要把多面板标成同轴融合。没有数据支持的构件不添加，新颖来自信息组织，不来自装饰。
- 个体/候选轻淡，代表/选定对象清晰突出；分类和语义取色保持可追踪。连续量使用对应配方的连续色图，离散状态使用离散分档，不能把所有渐变改成同一主题单色。

最终风格要明亮、舒适、有视觉重点；不为了塞更多图型牺牲 136 mm 最终引用下的可读性。默认按stage8-policy.md快速检查并一次集中修复重叠；用户明确只要首轮时不修。流程/框图统一主色，工程图原配色保留，批注方框白底。
