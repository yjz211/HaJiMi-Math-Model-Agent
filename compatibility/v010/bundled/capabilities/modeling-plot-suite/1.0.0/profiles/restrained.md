# 沉稳科研绘图模式 restrained

用户选择本模式时，优先于默认项目名风格抽签。沿用原版完整指南、配方预取、真实数据及最终尺寸预计算；本模式不改变计算结果。它是用户授权的设计偏好，不声称是 原始预设。

- 使用现有 colorblind 色板的原始顺序，蓝色为主、橙色或青绿承担必要对照，灰色用于背景/候选。白底，基础版式 clean_open；通过项目标记固定配置，setup_style 后读取 pu.PALETTE / pu.COLORS。
- 以标准、直接、易读为先：折线、误差图（仅有真实误差时）、热力矩阵、空间地图、普通散点、小多图；不为视觉冲击增加边缘分布或装饰性区域。对真实空间与工程任务积极采用三维透视、轴测、剖切及场分布等表达，遵循 upstream-planning.md；科研风格不等于仅画二维图。
- 每张图在现有规划中记录核心问题、配方、变量及颜色角色；不要求生成候选图。多面板仅用于不可省略的指标和必要对照，布局规整。
- 连续量使用合适的连续色图，离散覆盖用明确的分档/色条；同一对象颜色一致，线型和标记辅助识别。填充和网格克制，重点由线宽、标记及少量强调色表达。
- 图内以变量、单位、短图例为主；依据原版最终尺寸公式协调字号、线宽和画布。沉稳不是字小、颜色不可分辨或线条过淡。

默认遵循stage8-policy.md的一次集中重叠修复与轻量复核；用户明确只要首轮时不修。流程/框图统一主色，工程图原配色保留，批注方框白底。
