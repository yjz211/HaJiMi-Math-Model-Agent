# HaJiMi adapter: modeling-plot-suite

This compiled capability converts the global Codex plotting method into packaged HaJiMi resources. Runtime routing provides short fragments; detailed workflows, recipes, helpers, validators, renderers, and layout auditors live under `resources/`. Resolve `{capabilityRoot}` to this directory and run scripts with WSL `python3`.

The upstream font was deliberately omitted because its source snapshot did not include license metadata. Use an installed CJK font discovered at runtime or another licensed project font; never silently fabricate a font asset.
