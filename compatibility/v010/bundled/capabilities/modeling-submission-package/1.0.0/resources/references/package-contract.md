# 提交包契约

## 推荐根目录

```text
00_论文_含完整代码附录.pdf
01_论文_正文版_不含代码附录.pdf
AI工具使用详情.pdf
README_请先阅读.md
02_附录目录与代码对应表.md
03_代码文件说明.md
04_文件校验清单.csv
05_原文件名与提交文件名对照.csv
代码/
  README_代码复现说明.md
  B1_01_……
  B1_02_……
  B2_01_……
```

AI 详情只在官方要求或用户需要时加入。论文必须位于 ZIP 根目录，不能埋入多层文件夹。

## 附录与代码对应

- 论文附录先给出简洁目录，代码文件按附录 B1、B2……对应。
- 文件名采用“附录编号—过程顺序—中文用途”，例如 `B3_02_训练寿命预测模型.py`。
- 若一个附录含多个文件，使用 `B3_01`、`B3_02`；不要为凑编号建立空文件。
- 提交副本可改中文名，但源码内部 import 或相对路径会因此失效时，应保留可执行原名，或同步修改并实际运行验证。
- 主计算链、可选对照、图表生成和内部检查分开说明。

## 必要说明文件

- `README_请先阅读.md`：先打开哪份论文、代码位置、最短复现顺序、数据放置和未打包附件。
- `02_附录目录与代码对应表.md`：附录编号、提交文件名、用途和顺序。
- `03_代码文件说明.md`：各文件输入、输出、是否必需和依赖。
- `05_原文件名与提交文件名对照.csv`：原路径、提交路径、附录编号、用途、必需/可选。
- `04_文件校验清单.csv`：除自身外全部文件的相对路径、字节数和 SHA-256，路径统一使用 `/`。

## 默认禁入项

- 原始大数据和赛题附件：`.mat`、大型 `.csv/.xlsx`、原题 PDF/DOCX；最终按竞赛规则和用户要求决定。
- 编译缓存：`.aux`、`.log`、`.out`、`.toc`、`.synctex.gz`、`.fls`、`.fdb_latexmk`。
- 运行缓存：`__pycache__`、`.pytest_cache`、临时目录、渲染 PNG。
- 版本控制和内部材料：`.git`、工作流日志、审查报告、Agent 交接、废弃版本。
- 密钥、令牌、个人路径和含敏感信息的配置。

不能仅凭文件名 `B6/B7` 或目录 `tests` 一律排除；第009题的删除是题目特定决定。未来应按“是否为复现所需、官方是否要求、是否暴露内部材料”判断，并在配置中明确禁入模式。

## 版本一致性

1. 记录外部最新版论文的 SHA-256。
2. 复制到暂存目录后重新计算，必须一致。
3. 生成 ZIP 后读取 ZIP 内 PDF 字节并计算哈希，仍须一致。
4. 含代码版和无代码版应共享正文；可通过文本抽取、构建来源或用户确认核对。
5. 每次修改摘要、正文、参考文献或附录后都要重编、重复制、重算清单并重建 ZIP。

## ZIP 验收

- `ZipFile.testzip()` 或等价检查返回无损坏文件；
- 根目录论文、所需 AI 说明和 README 齐全；
- 没有空目录和禁入模式命中；
- 配置中每个必要代码文件都存在；
- 清单覆盖 ZIP 内除自身外的全部文件；
- 报告文件数、ZIP SHA-256 和包内 PDF 列表。
