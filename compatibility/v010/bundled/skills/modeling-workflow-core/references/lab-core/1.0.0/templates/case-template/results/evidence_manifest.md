# 结果证据表

论文中的关键数值必须从本表或对应的机器可读结果文件获取。

| 结果ID | 对应问题 | 指标/结论 | 数值 | 单位 | 原始结果字段/单元 | 来源程序 | 运行ID | 参数/配置/种子 | 验证证据 | 论文位置 | 验证状态 |
|---|---|---|---:|---|---|---|---|---|---|---|---|

## 验证状态

- `unverified`：尚未验证
- `checked`：完成基本检查
- `cross_validated`：已使用独立方法交叉验证
- `frozen`：允许进入论文定稿

## 登记规则

1. 一个结果 ID 只对应一个可明确核验的数值或结论。
2. 数值必须能定位到机器可读结果中的字段、记录或单元，不从图片反抄。
3. `运行ID` 必须对应 `experiments/` 中的运行清单。
4. 展示用的舍入、单位换算或百分比变换应在“指标/结论”或验证证据中说明。
5. 只有经过独立复现和审查的结果才能标记为 `frozen`。
