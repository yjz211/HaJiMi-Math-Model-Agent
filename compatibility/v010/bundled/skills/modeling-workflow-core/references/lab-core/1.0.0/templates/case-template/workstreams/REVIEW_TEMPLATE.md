优先级定义：

- P0：题意、数据或关键结论根本错误，必须停止后续工作。
- P1：会改变主要结果或论文结论，必须修复。
- P2：局部正确性、复现性或表达问题，应修复。
- P3：不影响正确性的改进建议。
