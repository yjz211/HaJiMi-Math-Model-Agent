## ⛔ TikZ 架构图分布规律（所有论文类型通用）

TikZ 图是论文结构的重要组成部分。不同章节位置对应不同类型的 TikZ 图，规划时参考以下分布规律自主决定：

### 位置一：绪论/引言（推荐）

**类型：技术路线图 / 研究框架图**
- 作用：让读者一眼看清整个研究的逻辑链路，从"问题→方法→验证→结论"的宏观视角
- 学术论文：研究框架图（研究问题→理论基础→方法设计→实验验证→结论）或技术路线图（数据采集→预处理→模型构建→训练→评估→部署）
- 统计建模：研究路线图（问题提出→文献梳理→假设建立→数据收集→实证分析→稳健性检验→结论）
- 数模竞赛：问题关系图（子问题间的依赖/递进/并行关系，标注数据流向）
- 风格：自上而下或自左向右的流程，节点用圆角矩形，箭头标注关键信息

### 位置二：方法/模型章节（推荐）

**类型：模型架构图 / 算法流程图 / 求解流程图**
- 作用：展示核心方法的内部结构和数据流
- 学术论文 CS/AI：整体模型架构图（输入→编码器→核心模块→解码器→输出），复杂模块可单独画细节图
- 学术论文 经管/统计：理论模型框架图（自变量→中介变量→因变量的路径关系，标注假设 H1/H2/H3）
- 统计建模：分析框架图（变量关系→模型选择→估计方法的逻辑）
- 数模竞赛：每个子问题的求解流程图（输入数据→预处理→建模→求解→输出结果）
- 风格：模块化布局，用不同颜色区分功能模块，箭头标注数据维度/变换

### 位置三：实验/实证章节（可选，推荐）

**类型：实验设计图 / 对比框架图**
- 作用：展示实验设计的整体结构（数据集划分、评估流程、对比方案）
- 适用场景：实验设计复杂（多阶段、多数据集、交叉验证）时特别有用
- 数模竞赛：灵敏度分析框架（哪些参数、变化范围、评估指标）

### ⛔ TikZ 不止架构图——按内容触发的高级数学/物理图（强烈推荐，竞赛与论文通用）

TikZ 真正"高级"的地方在于**原生渲染数学符号 + 精确几何控制 + 与正文字体完全统一**——这是 matplotlib 和 DrawIO 都做不到的。所以除了上面的架构图/流程图，凡论文（或竞赛的某一个子问题、论文的某一章）涉及下列内容，**应主动规划一张对应的 TikZ 图作为该问/该章的"点睛图"**，它往往比一张普通数据图更能体现专业度。

| 内容/方法特征（命中即考虑） | 应规划的 TikZ 图 | 典型放置位置 | 参考模板 |
|------------------------------|------------------|--------------|---------|
| 线性/整数/非线性规划、优化求解 | 可行域图（约束线+可行域+等高线+最优解） | 该问"模型求解" | M |
| 微分方程、动力系统、稳定性分析 | 相平面图 / 向量场 | 该问"稳定性分析" | E |
| 物理/力学场景（受力、斜面、约束反力） | 自由体受力分析图 | 该问"问题建模/假设" | F |
| 光学（成像、反射折射、激光路径） | 光路系统图 | 该问"问题背景/建模" | G |
| 平面几何、向量分解、几何证明 | 几何示意图（含中点/重心/角度标注） | 该问"几何分析" | J |
| **纯几何计算 / 多步几何推导**（螺线排布、覆盖宽度、等弦长递推、几何最优、临界位置）| **几何推导构造图**：坐标系+已知量+辅助线+**分步中间量标注**（$\theta_i,L_i,\Delta\varphi_i$），呈现"建系→递推→临界"的推导链，非一张静态示意 | 该问"几何建模/推导" | J 扩展 |
| 函数拟合、收敛过程、灵敏度曲线 | 函数图像（公式刻度与正文统一） | 该问"结果分析/灵敏度" | D |
| 神经网络/深度学习/集成模型 | MLP / CNN / Transformer 架构 | 方法/模型章节 | A/H/I |
| 物理约束建模、PINN、算子学习 | PINNs 架构图（含反向传播回环） | 方法章节 | L |
| 中介/调节/因果机制（经管/统计论文） | SEM 路径图 / 变量关系图（标注系数+显著性） | 理论模型章节 | （tikz_rules 模板7） |
| 综合评价（AHP/熵权/TOPSIS/模糊） | 指标体系树状图 | 数据描述/模型构建 | （DrawIO 或 TikZ） |
| 弹簧振子、机械连接、波动/阻尼 | 装饰路径片段嵌入物理图 | 该问"问题建模" | K |
| 电路网络、信号系统（电工杯等） | 电路图（circuitikz） | 该问"系统建模" | O |

完整可改编代码见 `tikz_examples_extra.tex`（模板 A–O）。配色与防遮挡规则见 `tikz_rules.md`。

**规划方法（竞赛 + 论文都适用）：**
- **竞赛**：逐个子问题评估——这一问的核心方法命中上表了吗？命中就为该问规划一张 `tikz_xxx`，写进 FIGURE_MANIFEST 的 TIKZ 类。例如"问题二用线性规划求解" → 规划 `tikz_feasible_q2`（可行域图）。
- **论文**：方法章节、理论章节、实证章节命中上表就规划。例如经管论文有中介效应 → 规划 `tikz_sem_path`（SEM 路径图）。

**⛔ 不要为画而画**：只在内容真正匹配时才加 TikZ 图——它是"这一问/这一章恰好有可精确刻画的数学结构"时的加分项，而不是每篇都硬塞。但反过来，**命中了却用普通数据图或文字代替，是浪费了一个体现专业度的机会**。

## ⛔ 领域特定"门面图"——感知/重构类任务必须有定性结果对比图（竞赛 + 论文通用）

有一类任务，其**核心产出本身就是可视的**——图像、视频帧、信号波形、频谱、分割掩膜、检测框、点云、生成/重构结果等。这类任务里，所有客观指标（PSNR/SSIM/NIQE/BRISQUE/CII/信息熵/平均梯度/边缘强度/mIoU/mAP…）**本质都是为了佐证肉眼可见的效果**。因此**定性结果对比图（处理前后 / 各方法之间并排 + 关键区域局部放大）才是这类论文的"门面图"，是评委最想第一眼看到的图，优先级最高，绝不能只堆指标图却漏掉它**。

规划阶段命中下表，**必须**在 FIGURE_MANIFEST 的 DATA 类里规划对应的 `fig_*_visual_cmp`（定性对比图），且优先级排在所有指标图之前：

| 任务特征（命中即必规划门面图） | 门面图内容 | 关键要点 | 放置位置 |
|------------------------------|-----------|---------|---------|
| 图像增强 / 去雾 / 去噪 / 低光增强 / 超分 / 去模糊 / 去反光 | 同一张真实图"增强前 ‖ 增强后"横向并排 + 关键细节区局部放大 | 红框标出标线/纹理/文字等关键区并放大到角落(inset)，证明"细节恢复且未过度平滑" | 每个增强子问题的"结果"节 |
| 图像分割 / 语义分割 / 实例分割 | 原图 / (GT若有) / 预测掩膜 三联，或掩膜半透明叠加原图 | 多类别配图例；叠加用 alpha≈0.5 | 分割结果节 |
| 目标检测 / 识别 / 定位 | 真实图上画预测框+类别+置信度，多方法/前后并排 | 漏检误检用不同颜色标注 | 检测结果节 |
| 图像重构 / 修复(inpainting) / 生成 / 风格迁移 / 配准 | 输入 / 输出 (/ 参考) 并排，多组样本纵向堆成蒙太奇 | 每行一个代表性样本 | 结果节 |
| 信号 / 音频 / 振动 处理、滤波、降噪、重构 | 处理前后时域波形或频谱并排/叠加 | 标出被滤除的噪声频段/恢复的特征 | 结果节 |
| 三维重建 / 点云处理 | 多视角渲染对比（输入稀疏 vs 重建稠密） | — | 结果节 |

**实现要点（matplotlib，无 GT / 无配对真值也照样能做）：**
- 用 `plt.subplots` 拼 N×2（前/后）或 N×3（含方法/GT）的蒙太奇网格，**每行一个代表性样本**——从不同退化等级/不同类别各抽 1 张真实图（如 clear/light/heavy 各一行）。
- 关键细节区用 `mpl_toolkits.axes_grid1.inset_locator.inset_axes`（或 `ax.inset_axes`）做局部放大，并在原图上用 `matplotlib.patches.Rectangle` 画红框标出对应位置——这是评委判断"细节是否恢复 / 是否过度平滑"的最直接证据，比任何指标都直观。
- 行/列标注用中文（与论文语言一致）：列标"输入""增强后"，行标"重度结冰""薄雪""清晰"等。关掉坐标轴刻度（`ax.axis('off')`）。
- ⛔ **用真实数据集样本，不要用 AI 生成的想象图**——有真实数据时，生成的"艺术想象图"反而削弱严谨性和说服力。
- 命名规范：`fig_<问号/场景>_visual_cmp`（如 `fig_q1_visual_cmp`、`fig_q2_visual_cmp`），写成 `(custom)` 配方（蒙太奇通常无现成配方编号），归入 FIGURE_MANIFEST 的 **DATA** 类（matplotlib 产出 .png/.pdf）。
- ⛔ **流水线依赖**：蒙太奇需要"处理后"的样本图存在。规划时同步要求求解代码（comp-code 阶段）把每类/每退化等级各 1–3 张代表性样本的**前后结果对**导出到固定目录（如 `figures/samples/q1_before_*.png` / `q1_after_*.png`），供 `fig_*_visual_cmp.py` 读取拼图——否则"增强后"那一列无图可拼。

**⛔ 反面教训（必读）**：某图像增强赛题规划了"指标增益发散柱状图 + 方法雷达图 + 得分热力图"等一堆漂亮的指标图，却**没有一张真实图像的 before/after 对比** → 本末倒置，等于用数字描述了半天却始终不给评委看实际效果。**命中上表却漏掉门面图，是规划阶段的致命缺陷**，优先级高于补任何一张指标图。

## ⛔ 按赛题领域的"标志图" + 鼓励自由设计（竞赛 + 论文通用，最高层规划心法）

**规划图表的第一步不是"从配方库挑几个类型"，而是先问自己两个问题：**
1. **这道赛题/这一问属于什么领域？这个领域的专家、评委打开论文最期待看到什么图？**（领域惯例图）
2. **我这一步算出了什么结果？什么样的视觉形式最能让人一眼看懂、并且相信它是对的？**（信息驱动）

配方库（basic / advanced / competition / empirical / academic 共 90+ 种）是**灵感菜单，不是限制清单**。命中库里类型就用编号；**库里没有、但更贴合这道题的图，大胆标 `(custom)` 自己用 matplotlib/TikZ 设计**——评委看的是"这张图有没有最贴切地讲清你的结果"，而不是"你用没用标准模板"。

### 按赛题领域的标志图触发表（命中即优先规划；不必每张都画，挑最能体现结果的）

| 赛题领域 / 特征（命中即考虑） | 该领域评委期待的"标志图"（自由取舍/组合） | 配方或 custom |
|---|---|---|
| 图像/视觉处理（增强/去雾/分割/检测/重构/生成） | 真实样本 before/after 对比 + 局部放大、掩膜叠加、检测框可视化（见上一节"门面图"） | custom / comp #10,#11 |
| 地理/空间/选址/覆盖 | 地理热力图、设施选址布局+覆盖半径圆、OD 流向图(流向线/弦图)、轨迹与路网叠加图 | comp #7,#18 / custom |
| 图论/网络/社交网络/电网 | 网络拓扑图(节点大小=度/中心性、颜色=社区)、最短路/最小生成树高亮、传播路径快照 | comp #16 / custom(networkx) |
| 路径/调度/物流(TSP/VRP/排产/车间) | 地图上的路线图、甘特图、时空轨迹图 | comp #15,#16 / custom |

| 预测/时间序列 | 预测vs实际带CI、残差诊断四联、多步衰减、序列分解 | empirical #12,#14,#16 / comp #8 |
| 分类/聚类/异常检测 | 混淆矩阵、ROC、t-SNE/聚类散点、SHAP/特征重要性、轮廓系数肘部图 | comp #10,#11,#13 / advanced #7 |
| 统计/计量/因果推断 | 森林图、DID 平行趋势、事件研究、安慰剂检验 | empirical #1,#2,#3,#4 |
| 金融/投资/风险 | 有效前沿、收益-风险散点、相关性热力、回撤/净值曲线 | basic #4,#5 / custom |
| 博弈/决策论 | 收益矩阵热力、博弈树(TikZ)、策略演化(复制动态)轨迹 | basic #5 / TikZ / custom |
| 信号/音频/振动/频谱 | 时域波形对比、频谱图、小波时频热力、功率谱密度 | custom(matplotlib) |
| 元胞自动机/Agent 仿真/交通流 | 多时刻状态网格快照序列(montage)、密度时空图、演化热力 | custom |

### ⛔ 自由设计的授权与底线

**鼓励发挥**：当某张图能让结果"一眼可信"，而配方库里没有完全对应的类型时，**主动设计定制图**——子图拼装(montage)、地图叠加、双轴联动、嵌套放大(inset)、时空序列快照、3D 场景渲染等都欢迎。一道好题的"点睛图"往往是为它量身定制的，而不是套来的。标 `(custom)` 写进 FIGURE_MANIFEST 即可。

**但守住四条底线（这是"可信度"的根，违反一条整张图作废）：**
1. ⛔ **数据必须真实**：图里每个数字都来自真实计算结果 / 真实数据（`figures/*_results.json`、`user_data/`），**严禁为了好看在画图脚本里硬编码编造数据**。没算出来就先去算，不要先画一张"漂亮但假"的图。
2. ⛔ **类型匹配语义**：排序/正值得分→排序条形图或棒棒糖图（**不要用发散柱**）；有正有负的增益/偏离→发散柱状图；"越小越好"的指标(NIQE/BRISQUE/RMSE/误差)进雷达图或综合评价前，**必须先反向归一化**统一成"越大越好"，否则面积/排名会误导。
3. ⛔ **要素完整**：坐标轴标题+单位、图例、中文标注(与正文一致)、必要时误差棒/置信区间；统计推断类结果不给不确定性=不可信。
4. ⛔ **最终清单零 TODO**：FIGURE_MANIFEST 和图表清单里不得残留 `TODO`/`待定`/占位类型，规划阶段就把每张图的类型定死。

## 竞赛论文

### 国赛 CUMCM A 题（优化类，25-30 页正文）

- 问题重述+分析(2-3页)：1 问题关系图(TikZ) + 1 数据特征表
- 模型假设+符号说明(1-2页)：1 符号表（三线表，15-25 个变量，含符号/含义/单位三列，不拆开）+ 模型假设 5-7 条
- 问题一(5-7页)：1 模型流程图(TikZ) + 2 求解结果表 + 3 结果可视化图(PDF，含空间分布/时序变化/对比) + 1 灵敏度分析图(PDF)

### 竞赛论文常用图表类型详解

**数据探索类**：
- 时序趋势图(Line)：多变量随时间变化的折线图，常用于问题一的数据特征分析
- 空间分布图(Heatmap/Contour)：地理或网格数据的热力图/等高线图
- 相关性热力图(Heatmap)：变量间相关系数矩阵，颜色编码
- 散点图矩阵(Pairplot)：多变量两两关系的散点图网格
- 直方图/核密度图(Histogram/KDE)：数据分布形态展示
- 箱线图(Boxplot)：分组数据的分布对比

**模型结果类**：
- 拟合对比图(Fit)：模型预测值 vs 实际值的散点图或折线对比
- 收敛曲线(Convergence)：优化算法的目标函数值随迭代次数变化
- Pareto 前沿图：多目标优化的非支配解集
- 残差分析图(Residual)：残差分布、Q-Q 图、残差 vs 拟合值
- 混淆矩阵热力图：分类模型的预测结果矩阵
- ROC 曲线/AUC：分类模型性能评估
- 特征重要性图(Bar)：随机森林/XGBoost 等模型的变量重要性排序

**灵敏度分析类**：
- 参数敏感性曲线：单参数变化对目标函数的影响
- 龙卷风图(Tornado)：多参数灵敏度排序对比
- 蒙特卡洛模拟分布图：参数不确定性下的结果分布

**方案展示类**：
- 优化方案布局图：设施选址/路径规划/资源分配的空间展示
- 甘特图(Gantt)：调度问题的时间安排
- 网络拓扑图：图论问题的节点-边关系
- 三维曲面图(Surface)：双参数对目标函数的联合影响

**架构/流程类（TikZ）**：
- 模型整体流程图：问题→数据→模型→求解→结果的流程
- 算法流程图：关键算法的步骤分支
- 问题关系图：多个子问题之间的逻辑关系

**🔥 高级图表（figure_recipes_advanced.md ## 25-34，AI 难自己画好的标准化图）**：
- **Performance Profile (Dolan-Moré)** [#25]：多算法跨问题求解时间对比标准画法（运筹/OR/优化类竞赛必备）。X 轴 τ 对数刻度，Y 轴 ρ(τ) 累计概率，阶梯函数。比柱状图信息密度高得多
- **ICE + PDP** [#26]：可解释机器学习。多条 ICE 细线展示样本异质性，粗 PDP 均值线表示总体效应，底部边际分布告诉读者 PDP 在哪些 x 上有数据支撑
- **Fan Chart** [#27]：预测扇形图（预测类问题必备）。多层 CI 带 50%/80%/95%，历史区实线 + 预测区虚线 + 终点不确定性范围标注。央行/COVID/能源预测标准画法
- **Calendar Heatmap** [#28]：日历热图（时序观察）。7×53 周历网格，GitHub 贡献图风格，一眼看出周期 / 节假日 / 异常日
- **Hovmöller** [#29]：时空二维图（气候/海洋/水文）。时间纵轴 + 空间横轴 + 双向色阶 RdBu_r，事件用矩形框标注
- **Pair Plot / Scatter Matrix** [#30]：多变量数据探索。N×N 网格，对角线 KDE + 上三角相关系数（背景色映射强度）+ 下三角散点拟合
- **Triptych 三联图** [#31]：CV/AI 定性结果（input/中间/output 横向并列 + 流向箭头 + 共享 colorbar）。比纯指标表能让评委一眼信服
- **Posterior Trace + Density** [#32]：贝叶斯 MCMC 收敛诊断标配。左 trace 看混合 + 右边际密度 + HPDI + Rhat
- **Streamgraph** [#33]：流图。居中堆叠基线展示多类别时序占比，比堆叠柱状图更动态
- **Bivariate Choropleth** [#34]：双变量空间分布（地理风险×暴露、降水×气温）。3×3 配色矩阵作图例

> 这 10 个图共同特点：**AI 不熟悉标准画法**，自己写代码很容易出错（轴方向画反、阶梯没用 step、CI 带颜色脏、相关性矩阵字号没映射强度等）。**有针对性的问题命中时强烈建议用配方**。

## 学术论文常用图表类型详解

### 计算机/AI 方向

**实验对比类**：
- 性能对比柱状图(Bar)：多方法在多指标上的对比，分组柱状图或堆叠柱状图
- 训练曲线(Line)：loss/accuracy 随 epoch 变化，常含 train/val 两条线
- 收敛对比图：不同方法的收敛速度对比
- 消融实验柱状图：逐步移除/添加模块的性能变化
- 超参数敏感性图：关键超参数（学习率/层数/维度）对性能的影响曲线

**可视化分析类**：
- t-SNE/UMAP 散点图：高维特征的二维投影，颜色编码类别
- 注意力热力图(Attention Map)：Transformer 等模型的注意力权重可视化
- 特征图可视化(Feature Map)：CNN 中间层的激活可视化
- 梯度类激活映射(Grad-CAM)：模型关注区域的热力图叠加
- 混淆矩阵热力图：分类任务的预测结果矩阵

**案例展示类**：
- 定性对比图(Qualitative)：多方法在同一输入上的输出对比（图像/文本/生成结果）
- 失败案例分析(Failure Cases)：模型失败的典型样例及原因分析
- 渐进生成图：生成模型不同步骤的中间结果

**架构类（TikZ）**：
- 整体架构图：模型的模块组成和数据流
- 模块细节图：核心模块的内部结构
- 算法伪代码(algorithmic)：关键算法的形式化描述

### 经管/统计方向

**数据描述类**：
- 核密度图(KDE)：连续变量分布，常用于收入/价格等偏态变量
- 箱线图(Boxplot)：分组变量分布对比
- 相关性热力图(Heatmap)：变量间相关系数矩阵
- 时序趋势图(Line)：关键变量的年度/季度变化
- 地理分布图(Choropleth)：省份/城市级别的变量空间分布

**因果推断类**：
- 平行趋势图(Parallel Trends)：DID 前提检验
- 动态效应图(Event Study)：逐期系数及置信区间
- 安慰剂检验图(Placebo)：随机抽样系数分布
- RDD 断点回归图：断点两侧散点+拟合线
- PSM 平衡性检验图(Love Plot)：匹配前后协变量标准化偏差

**回归结果类**：
- 系数森林图(Forest Plot)：多模型核心系数及置信区间
- 边际效应图(Marginal Effects)：交互项的条件边际效应
- 分位数回归图(Quantile)：不同分位点的系数变化
- 异质性分组对比图(Subgroup)：分组系数对比

**诊断检验类**：
- 残差诊断图：残差 vs 拟合值 + Q-Q 图
- VIF 多重共线性柱状图
- Cook's Distance 影响点检测图
